Project 1 · Web application

Role-based workforce & performance dashboard

Problem
Attendance, schedules, KPIs, bonuses and coaching lived in separate Excel files, updated by hand and shared by email. Every role saw either everything or nothing.
What I built
  • One web app with seven views: Agent, Line Manager, QA, WFM, Operations Manager, Senior OM and Admin.
  • Single sign-on with row-level security, so each person only sees their own data or their own team.
  • WFM tools: schedule builder with automatic breaks, PTO requests and approvals, late-exception handling.
  • A digital coaching form with e-signatures, monthly completion tracking and PDF export.
Result
Managers, agents and WFM work from one live source instead of emailed spreadsheets.

Project 2 · Data engineering

Automated cloud data pipelines

Problem
Reports depended on someone downloading CRM exports and running scripts on a laptop every day. A missed day meant a gap in the numbers.
What I built
  • Eight scheduled Azure Functions that pull KPI, customer-satisfaction, QA, roster, schedule and attendance data into Azure SQL.
  • Secrets in Azure Key Vault and managed identities, so no passwords are stored anywhere.
  • Adaptive search-window splitting to get past a 10,000-record API limit, plus retries for rate limits.
  • Backfill and single-day recompute tools for correcting past dates.
Result
The data refreshes unattended every day, and live login status every 30 minutes.
Azure FunctionsREST APIsMicrosoft GraphKey VaultT-SQLAzure DevOps CI/CD
Project 3 · Business rules engine

Scorecard & incentive calculator

Problem
Monthly bonuses came from a complex Excel workbook: weighted KPIs, rating bands, attendance multipliers, tenure and disciplinary rules, all checked by hand.
What I built
  • A Python engine that rates each agent on four weighted KPIs against agreed bands and applies the payout curve.
  • Attendance qualifiers, tenure and disciplinary gates, and prorating for agents who resign mid-month.
  • Month-to-date previews for agents, then a locked final run once the month closes.
  • A separate scorecard for Line Managers, including team retention and coaching completion.
Result
Bonuses for 85+ agents are calculated the same way every month, and every agent can see why they earned what they earned.
PythonSQLBusiness rulesData validation
How I build

AI-assisted development, with production discipline

I use Claude as a development partner to design, write, test and document features. The speed comes from AI; the reliability comes from the process around it:

  1. Audit the existing code and data before changing anything.
  2. Make the smallest change that solves the problem, isolated to the role or page it affects.
  3. Write database changes as numbered scripts that preview first and roll back by default.
  4. Check each fix against real data before it ships.
